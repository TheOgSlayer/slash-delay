# SlashDelay

Paper plugin (1.20.6+, Java 21). Typing `/` shows no command suggestions;
typing `/t` shows `/tp` and friends.

## Get the jar
1. Push this repo to GitHub.
2. Open the **Actions** tab, run/open the latest **Build** run.
3. Download the **SlashDelay** artifact, unzip, and put `SlashDelay.jar` in `plugins/`.

## Notes
- Command syntax highlighting while typing is lost (client sees a generic tree).
- Give players `slashdelay.bypass` to keep vanilla behaviour.
- Untested on a live server: try it on a dev server first.
